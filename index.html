Versão inicial

Vincule um token e cadastre os valores da ficha. A leitura automática da conta CRIS ainda depende de uma API/exportação autorizada.

1. Dados da ficha

Formato JSON aceito: {"name":"Agente","pv":32,"pvMax":40,"san":18,"sanMax":35,"pe":12,"peMax":20}

2. Token selecionado

Selecione um token na mesa e use o menu de contexto: “Vincular ficha CRIS”.

3. Visualização

O botão de olho no menu do token alterna a exibição das barras daquele personagem.
